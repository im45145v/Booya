Booya 0.2.1 fixes screen recording on current macOS.

## Fix: macOS recording hung or produced no video

ffmpeg's `avfoundation` screen input (AVCaptureScreenInput) is deprecated and delivers no frames on recent macOS (tested on macOS 27 with an Apple Silicon Mac, where it logged `Configuration of video device failed` and wrote nothing). Booya now captures the screen with **ScreenCaptureKit**.

- Frames from an `SCStream` are piped to the bundled ffmpeg as raw video and encoded as before (hardware H.264 where available).
- The cursor is not captured (Booya draws its own), and the Booya window and the REC badge are excluded from the recording.
- Screen, area and window capture (window by id or title, from the CLI).
- The microphone still uses an audio-only avfoundation input, and prefers the built-in microphone over a Bluetooth headset.
- A missing Screen Recording permission now shows a clear message with the exact Settings path, and the system prompt is requested.
- The old backend is only used if you set `BOOYA_MAC_CAPTURE=avfoundation`.
- macOS 12.3 or newer is required (ScreenCaptureKit).

## New: `booya doctor`

```bash
booya doctor
```

Prints JSON with the Screen Recording permission, the displays ScreenCaptureKit lists, the ffmpeg in use and the result of a 3 second test capture (file size, frames, resolution). Exit code 1 when the test capture fails, with `next_steps` saying what to do.

## Packaging

- ffmpeg, ffprobe and the app are all ad-hoc signed with the hardened runtime, and the release build now fails if any helper is not. The command line tool is signed too.
- The app is still not notarised, so Gatekeeper warns on first open. Run `xattr -cr /Applications/Booya.app` once after copying it. Because the signature is ad-hoc, macOS treats each update as a new app: if recording stops after updating, remove Booya from Screen & System Audio Recording, add it again and reopen it.

## Known limits

- System audio on macOS still needs a loopback device such as BlackHole.
- This release was built and checked on CI. It has not been run on every Mac, so please run `booya doctor` and report what it prints if recording fails.
