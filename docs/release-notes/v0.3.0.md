DemoLens 0.3.0 adds the features that other demo tools charge for, keeps them local and free, and fixes the gaps found in the competitor review (see [docs/COMPETITORS.md](https://github.com/im45145v/DemoLens/blob/main/docs/COMPETITORS.md)).

Like 0.2.2, this was built and tested on CI and a Linux box. It has **not been run on a Mac by the author**. The macOS-only parts (key capture, ScreenCaptureKit audio sync) are the ones to test first, see "Check it on your Mac".

## New
- **Interactive demo export**: `demolens interactive demo.json -o demo.html`, or the Magic tab. One self-contained HTML file: a click-through built from your recording and its event log, with a screenshot per click, a hotspot, step captions, keyboard and swipe navigation and an optional call to action. Blur boxes are applied to the screenshots. The file makes no network calls. Share it with a signed link from Export.
- **Webcam layouts**: bubble (corner, circle or rounded square) or **side by side** with the screen in the remaining space, plus mirror. The camera now shows in the editor preview too (it only appeared in the export before).
- **Steadier auto zoom**: the camera aims where the action will be, holds still while the cursor wanders inside a dead zone and follows only when it nears the edge of the view. A **Steadiness** slider and **Subtle / Moderate / Intense** zoom styles in the Style tab.
- **Background photos**: pick a png, jpg, heic or webp as the background. Fit, fill or blur, dim, recent images, copied into the project folder so the project stays portable.
- **Intro and outro cards**: a title and subtitle on your background, faded in and out, with silence under the intro and the sound kept in sync.
- **Callouts**: timed text notes on the video ("Click here"), added at the playhead, in the Edit tab.
- **Watermark**: optional text in any corner. Off by default. Never added by us.
- **Richer presets**: a saved look now also keeps the watermark, caption style and zoom settings. Old presets still load.
- **First-run checklist** on the welcome screen, ticked off as you record, make a demo and export.
- **Share an interactive demo** through the same private signed link as videos.
- **macOS key capture** (opt-in): a CoreGraphics poller records shortcuts and the timing of typing, never characters. It needs Input Monitoring; turning on the keyboard button explains what to allow. Untested on real hardware.

## Fixes
- The editor preview never drew the webcam (fixed).
- A project with a watermark could be exported by a straight copy that skipped it; any watermark, callout or card now forces a real render.
- Background controls in the Style tab clashed with the fit buttons (separate selectors now).
- Loudness gate: very quiet recordings were treated as silence at -58 LUFS; the floor is now -65.

## Check it on your Mac
1. Record 20 seconds while talking, click a few buttons and type a sentence, with the keyboard button on. Allow Input Monitoring if asked, then restart the app.
2. Open it. Style tab: try the Zoom style menu and Steadiness, add a watermark, an intro and outro, then export. Edit tab: add a callout at the playhead.
3. Magic tab: **Interactive demo** and open the HTML in a browser.
4. Run `demolens verify <recording.mp4>` and tell me the offset it reports.

## Honest limits
- Not notarised. macOS asks for Screen Recording, Microphone and now Input Monitoring again after each update, because the app is ad hoc signed.
- System audio still needs a loopback device such as BlackHole.
- Multi-clip projects, AI script cleanup and voice retakes, iPhone capture, transcript editing and a camera cutout are not in this release.
- Intro and outro cards show in the export, not the editor preview. The preview is rendered by our own engine, so very small differences from the export are possible.
