DemoLens 0.2.0 is a privacy and security release, with drawn blur boxes, a webcam overlay, WebM export and optional cloud AI.

## Security advisory: please upgrade from 0.1.x

A review of every earlier release (0.1.0 to 0.1.3) found issues that are fixed here. Full details are in [docs/SECURITY_AUDIT.md](https://github.com/im45145v/DemoLens/blob/main/docs/SECURITY_AUDIT.md).

- **High: typed characters were saved in the event log.** On Linux and Windows, `recording.events.jsonl` next to each recording stored the keys you pressed, including anything typed into password fields. **Delete or check the `.events.jsonl` files from old recordings**, especially any you shared. 0.2.0 never stores characters, key capture is off by default, and old logs are masked when opened.
- **High: the keyboard hook stayed active after recording stopped,** until the app was closed. It now runs in a separate process that ends with the recording.
- **High: the editor window could write files anywhere.** Writes are now limited to files you picked in a dialog, with a strict Content Security Policy.
- **Medium:** the "local only" LLM check could be fooled by a host name such as `localhost.example.com`; model downloads were not hash checked; auto blur missed Aadhaar, PAN, UPI, IBAN, IPs, bearer tokens and password fields; there was no recording indicator.

No data was ever sent to the DemoLens maintainer. There is no telemetry.

## Privacy
- Always on top REC badge with a timer and Pause (Ctrl/Cmd+Shift+P). Paused parts are cut.
- Key capture is opt-in per recording and only keeps shortcut names and typing timing.
- Private folders and logs, automatic deletion of old recordings, delete one or all recordings in Settings > Privacy.
- A review step before export: "Auto blur may miss text. Watch the export before sharing."
- New [PRIVACY.md](https://github.com/im45145v/DemoLens/blob/main/PRIVACY.md) and a Privacy section in the README.

## New
- **Draw blur boxes** with the mouse, and **pick the area to record** on a screenshot.
- **Webcam overlay**: circle or rounded square, any corner, any size.
- **WebM export**, and 9:16 and 1:1 presets for Reels, Shorts and feed posts.
- **Optional cloud AI**, off by default, with your own keys in the OS keychain: speech to text, writing and text to speech through OpenAI, Anthropic, Google Gemini, Google Gemma, Groq, OpenRouter, Deepgram, AssemblyAI, ElevenLabs, Backboard or any OpenAI compatible endpoint. Each task is opted into separately, and every call shows what is sent first.
- **Optional upload** to your own S3 or R2 bucket as a private object with an expiring link.

## Better results
- Typing shows as "Typing..." placed clear of the cursor, one cursor only, smoother cuts (short crossfades) and better captions (Whisper small.en by default, voice activity detection, filler and stutter cleanup).
- Faster: a persistent preview decoder for playback, no re-encode when nothing was edited, transcripts cached, and OCR skips unchanged frames.
- Zoom segments can no longer be dragged over each other.

## Not in this release
- Wayland capture (use an X11 session).
- Intel Mac installers (build from source with `--target x86_64-apple-darwin`).
- On Linux the REC badge can appear in the recording; on macOS and Windows it is hidden from capture.
