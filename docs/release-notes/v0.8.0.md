Booya 0.8.0 keeps voice and picture in sync, starts recording about 5 seconds sooner, exports faster, and adds export cancel, caption looks, a draggable camera bubble and a No background option.

## Sync
- Voice, camera and auto zoom now run on one clock (#14).
- When system audio was recorded along with the mic, the mic's clock correction was skipped. Over a couple of minutes that could drift by about a quarter of a second and pull captions with it. The correction now runs in both cases (#39).
- If the mic stopped sending sound for a few seconds partway through a take, Booya closed up the gap, so every word after it played early by the length of the gap. This could show up as an offset of several seconds. Each gap is now put back as silence, and `audio.log` gets a `microphone clock:` line that lists any gaps it found (#40, #7).

## Faster
- Recording starts about 5 seconds sooner with the mic on. The countdown used to wait for ffmpeg to write its first 5 second block of audio; it now writes every quarter second. `audio.log` gets a `start timing:` line showing how long each recorder took to start (#41).
- Export decodes, draws and encodes at the same time. A 4K test export went from 25.8 s to 14.1 s (#27, #10).
- Decoding a long recording uses about half the memory (#28).

## New
- Cancel an export, and see about how long it has left (#34, #6).
- Caption looks: box, outline or pop, at the bottom, middle or top (#31).
- Drag the camera bubble anywhere on the preview, and scroll to resize it (#29).
- No background: just the recording and the camera, edge to edge (#37, #8).
- Booya says so when the screen recorder stops mid recording, and warns when free disk space drops under 2 GB (#30).
- Recording time in the tray, and Linux icons (#17).
- Auto edit cancel and camera layout options (#11).
- New look: Ghost x Ink mono (#15).

## Fixes
- Touch on a touch screen that is not the primary monitor lands in the right place on Windows (#38).
- Clicks and zoom land in the right place on displays with different scaling (#24).
- On macOS, key logging set to Off no longer starts a key watcher (#21).
- Projects, settings and exports are written safely, so a crash never leaves a half written file, and an export can't overwrite one of its own inputs (#19).
- An update install or a delete can't run during a recording (#25).
- One panic no longer takes down Stop or the whole app (#32).
- Windows: Show in folder works with spaces in the path, and models are extracted with the system tar (#33).
- Two caption wrap bugs for Telugu and Hindi, found by new property tests (#26).

## Things to do

## Not tested on real hardware
The sync changes in #39 and #40, the faster start in #41 and the touch fix in #38 were checked by CI and unit tests only. A clap test on a real Mac and Windows PC, and touch on a second monitor, have not been done for this build.
