DemoLens 0.1.1 fixes the macOS "DemoLens is damaged and can't be opened" error. The macOS app is now signed ad hoc, so Gatekeeper treats it as an app from an unidentified developer that you can allow, instead of a broken one. Everything else is the same as 0.1.0, the first public release of DemoLens: a free, offline screen recorder that turns a raw recording into a polished product demo on Windows, macOS and Linux.

## Highlights

- **Auto zoom** on every click and typing burst, with a smooth cursor, click ripples and a keystroke overlay.
- **Make it demo-ready**: one button adds zooms, captions, cuts filler words and long pauses, blurs secrets and cleans the audio. Each step reports what it did and one undo reverts it all. Also available as `demolens ready`.
- **Local AI, fully offline**: captions (Whisper), auto cut of fillers and pauses, auto blur of emails, API keys, card numbers and phone numbers, background noise removal, and written docs (title, chapters, step by step guide, social post). Models are optional downloads.
- **Templates**: Sunset, Midnight, Ocean, Clean light, Minimal and Social card, plus your own saved presets.
- **Export presets**: YouTube, X and LinkedIn, feed post 1:1, Reels and Shorts 9:16, README GIF and 4K 60, in MP4 or GIF.
- New editor with dark and light themes, a zoomable timeline with draggable zoom segments, and keyboard shortcuts (press `?`).
- A scriptable command line tool for recording, editing and exporting.

## Downloads

- Windows: `.msi` or `-setup.exe`
- macOS (Apple Silicon): `.dmg`
- Linux: `.deb`, `.rpm` or `.AppImage`
- Command line tool: `demolens-cli-*` archives

## Known limits

- **Builds are not signed with a paid certificate.** Windows SmartScreen may warn you (choose More info, then Run anyway). On macOS see below.
- **ffmpeg is required** and is not bundled. Install it from https://ffmpeg.org/download.html and make sure it is on your PATH.
- **No Wayland capture yet.** On Linux, use an X11 session to record.
- No Intel Mac build in this release.

## Opening DemoLens on macOS

The macOS app is signed ad hoc, not with a paid Apple Developer ID, so Gatekeeper blocks it the first time. Use any one of these:

- Right click (or Control click) DemoLens in Applications, choose **Open**, then **Open** again.
- Or try to open it once, then go to **System Settings > Privacy & Security** and click **Open Anyway**.
- Or, if macOS says the app "is damaged and can't be opened", run this in Terminal and open it again:

  ```sh
  xattr -cr /Applications/DemoLens.app
  ```

  This removes the download quarantine flag that your browser added. The app is not actually damaged.
