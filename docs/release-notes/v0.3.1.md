DemoLens 0.3.1 is the "make it intuitive and make editing richer" release: a visual picker for what to record, drawn annotations, three new timeline lanes, wallpapers and a transcript panel.

Like the releases before it, this was built and tested on CI and a Linux box. It has **not been run on a Mac by the author**. The ScreenCaptureKit picker previews are the first thing to check, see "Check it on your Mac".

## New
- **Visual source picker** (replaces typing a display number, window id or coordinates). Click the source button next to Record:
  - *Screens*: one card per display with a live preview.
  - *Windows*: one card per open window with the app icon, the window title, a live preview and search. Previews load as you scroll.
  - *Area*: a screenshot of the screen to drag a rectangle on. Move it, resize from the corners, snap to Free, 16:9, 4:3, 1:1, 4:5 or 9:16, or type X, Y, W and H.
  - `demolens sources [--thumbs dir]` prints the same list as JSON and can save the previews, so a problem is easy to report.
- **Shapes**: arrow, box, ellipse and highlight, drawn by dragging on the preview, in six colours, with a length. They fade in and out, are anti-aliased in the export, and can be moved, resized (drag the edges on the timeline) and removed.
- **Timeline lanes**: *Notes* (callouts and shapes), *Blur* (every blur box) and *Keys* (what the keystroke overlay shows, and when). Notes and blur items can be dragged to move, stretched from either edge, selected and deleted with Delete.
- **Wallpapers**: twelve soft four-colour backgrounds in the Style tab (Aurora, Sunset, Ocean, Candy, Forest, Midnight, Peach, Lavender, Slate, Citrus, Dusk, Mint).
- **Transcript panel** (Edit tab): fix caption text (word timings are kept), find and replace across the transcript, jump to a line, or **Cut line** to remove that part of the video.
- Recent background photos load their thumbnails only when you see them.

## Fixes and changes
- Single-frame editor previews no longer start a VideoToolbox session per scrub on macOS, which is the likeliest cause of slow seeking there. The proxy already keeps a keyframe every 15 frames, and a test now checks it. Set `DEMOLENS_HWACCEL_FRAMES=1` to turn the old behaviour back on if it turns out to be faster for you.
- A project with shapes is always rendered (never a straight copy), like callouts and watermarks.

## Check it on your Mac
1. Run `demolens sources --thumbs ./t`. You should see one `.png` per display and window. Send me the JSON if a window is missing or has no preview.
2. Open DemoLens, click the source button, try all three tabs, pick a window and record 10 seconds. Screen Recording permission is needed; previews need macOS 14 or newer (older systems show a placeholder and still record).
3. Edit tab: draw an arrow and a highlight on the preview, drag them on the Notes lane, then export.
4. Scrub the timeline and tell me if seeking feels faster or slower than 0.3.0.

## Honest limits
- Shapes are placed on the output frame. They do not move with the zoom camera.
- Notes and blur items cannot be dragged to a different lane, and the Keys lane is read-only.
- The Linux picker previews a region grab, so an overlapped window shows whatever is on top of it. The macOS picker captures the window itself.
- The Windows window list uses PowerShell and is untested on a real PC.
- Not notarised; macOS asks for permissions again after each update. System audio still needs a loopback device. Multi-clip projects, AI script cleanup, voice retakes and iPhone capture are still not done.
